網路不通？

English

網路不通的時候，請照著下面的順序一步一步檢查。做到哪一步不通，就停在那一步照著處理，大部分的問題在第 1、2 步就解決了。

以下畫面以 Windows 11 為例。Windows 10 與 macOS 的畫面位置不同，但檢查的順序完全一樣。
如果你有接 Wi-Fi 分享器，請先把網路線從分享器上拔下來、直接接到電腦測試，這樣才知道問題是出在分享器還是線路。

  1. 先確認電腦有沒有「看到」網路線

    對右下角的網路圖示點擊右鍵，再點擊「網路和網際網路設定」。

    看最上面「乙太網路」下面那一行字寫什麼。

    寫著「已拔除電纜」、「未連線」或「未識別的網路」

    代表電腦收不到線路的訊號，通常不是設定的問題。請依序試試看：

    • 把網路線兩端重新拔起來再插回去，插到聽見「喀」一聲。水晶頭上的卡榫斷掉是最常見的原因，卡榫斷了就換一條線。
    • 借室友的網路線接接看，確認是不是自己的線壞了。
    • 把線接到牆上的另一個網路孔試試。注意：每個網路孔的 IP 不一樣，換孔之後要回本站重新查那個孔（床位）的 IP。
    • 用 USB 轉 RJ45 轉接頭的人：換一個 USB 孔，並確認轉接頭的驅動程式有安裝好。
    • 以上都試過還是「已拔除電纜」，那可能是網路孔或線路故障，請直接報修（見第 4 步）。
    根本找不到「乙太網路」這個項目

    代表 Windows 沒有抓到網路卡。電腦本身有網路孔的話，請更新網路卡的驅動程式；用轉接頭的話，請換一個 USB 孔或安裝轉接頭的驅動程式。

    寫著「已連線」或「無網際網路存取」

    代表線路沒問題，請接著做第 2 步，檢查 IP 設定。

  2. 檢查 IP 設定有沒有填對

    先查出自己床位的四組數字：IP 地址、子網路遮罩、預設閘道、DNS 伺服器。 回首頁查詢。

    接著打開設定 → 網路和網際網路 → 乙太網路，往下拉找到「IP 指派」，把畫面上的數字跟查到的一個字一個字對過。

    要修改的話，點「IP 指派」旁邊的「編輯」，詳細步驟請看 網路設定教學。

    最常見的錯誤：

    • 「IP 指派」還是顯示自動 (DHCP)。宿舍網路不會自動給 IP，一定要改成手動。
    • 填成室友的、或別的床位的 IP。
    • 編輯視窗裡的 IPv4 開關沒有打開，或是填完忘記按「儲存」。
    • 子網路遮罩或預設閘道少打、多打了一位數字。
    • DNS 伺服器沒有填 210.240.232.1。

    想快速確認：按 Win + R，輸入 cmd 後按 Enter，再輸入 ipconfig。 如果 IPv4 位址是 169.254 開頭，代表設定沒有生效，電腦還在自動取得 IP。

    確定填對了還是不通？把同房間每一床的 IP 都試一次

    有些房間牆上網路孔的排列順序跟床位是相反的（例如 1 床旁邊那個孔，其實是 4 床的），所以你選的床位不一定就是你實際插的那個孔。

    回到自己的房間頁面，依序點 1 床、2 床、3 床⋯⋯，把每一組數字都填進去試試看，哪一組能上網，那組就是你這個孔的 IP。

    室友已經在用的那幾組就跳過不要試，兩台電腦用同一個 IP 會互相斷線。

  3. 用 ping 一段一段找出斷在哪裡

    按 Win 鍵，直接輸入 cmd 再按 Enter，開啟「命令提示字元」，然後依序輸入下面的指令（每打完一行按 Enter）。 第一個不通的地方，就是問題所在。

    1. ping 127.0.0.1

      測試自己的網路卡。不通：網路卡驅動程式有問題，請重新開機或重裝驅動程式。

    2. ping 192.168.___.254

      請換成你自己的預設閘道。測試到宿舍樓層網路設備的連線。不通：回第 1、2 步再檢查一次，並照第 2 步的說明把同房間每一床的 IP 都試過；線路與設定都確定沒問題卻不通，可能是網路孔沒開通或 IP 被封鎖，見第 4 步。

    3. ping 210.240.232.1

      這是學校的 DNS 伺服器，測試校內網路。不通：校內線路有問題，見第 4 步。

    4. ping 168.95.1.1

      這是中華電信的 DNS，測試學校對外的網路。不通：學校對外線路可能有狀況，過一陣子再試試。

    5. ping www.google.com

      測試網址解析（DNS）。前面都通，只有這個不通：DNS 沒設定好，回第 2 步把 DNS 伺服器填成 210.240.232.1。

    怎麼看結果：

    • 出現「回覆自 …: 位元組=32 時間=1ms」→ 通了。
    • 出現「要求等候逾時」、「一般失敗」、「目的地主機無法連線」→ 不通。
    • 全部都通，但只有某個網站打不開 → 多半是那個網站自己的問題，換別的網站試試看。

  4. 都試過還是不行，怎麼求助

    • 跳出「偵測到 IP 位址衝突」：代表有別人用了跟你一樣的 IP。先確認自己填的真的是自己床位的 IP，確認沒填錯就要反映。
    • 懷疑 IP 被封鎖：電腦中毒或流量異常會被停權，也請反映。
    • 反映方式：用手機或其他可以上網的裝置，寄信到 cc@mail.mcut.edu.tw，信裡寫上姓名、學號、宿舍與寢室（例如 五宿 501）、床位、網路孔上的編號、你設定的 IP，以及你已經試過哪些步驟。
    • 電話：02-2908-9899（圖書館分機 2280、電算中心分機 2270）。
    • 網路孔壞掉或沒開通，也可以找宿舍的網管或舍監協助報修。
